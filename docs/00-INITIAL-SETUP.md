# Part 00 - Initial Expo Setup

## Owner

Developer.

Claude must not perform this phase.

## Objective

Create the initial Expo React Native project before Claude begins implementation.

## Developer Tasks

1. Create the Expo project in the preferred development directory.
2. Select TypeScript.
3. Use the current Expo Router-compatible setup if Router is part of the initialized template.
4. Start the project successfully.
5. Confirm the project opens on the intended development target.
6. Commit the clean initial state if using Git.
7. Give Claude the initialized repository.

## Important

Claude must not:
- run `create-expo-app`
- recreate the project
- wipe the repository
- replace package.json unnecessarily

## Handoff Requirements

The project should contain:
- package.json
- app configuration
- TypeScript configuration
- existing Expo entry structure
- assets directory if created
- Git repository if applicable

Claude should inspect all of these before Part 01.
